Frequently Asked Questions

Why does the Stem Separator run via Google Colab?
Demucs AI requires deep learning neural hardware (~2 GB RAM and GPU acceleration) to isolate stems accurately. Running the model on free cloud GPUs keeps ToneVault 100% free with zero installation requirements for users.
What is the difference between HTDemucs and MDX-Extra?
HTDemucs is optimized for high-speed execution (~1 minute per track) with balanced frequency isolation. MDX-Extra takes slightly longer to render but delivers maximum isolation quality on dense EDM and rock arrangements.
Is there any file size or duration limit?
Because the separation runs on cloud GPU hardware, you can process full-length songs (up to 10+ minutes) without hitting browser memory limits or system crashes.
